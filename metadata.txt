about=
    Cartomancy brings AI image generation into the QGIS Print Layout / Print
    Composer window. Instead of drawing a selection box on the map, the map
    frame in your layout *is* the region — and its paper size and export DPI
    define the exact output resolution. Type a prompt, generate, and receive a
    georeferenced GeoTIFF at the resolution you intend to print.

    • Edit at exact print resolution — no guessing, no upscaling, no wasted credits
    • Georeferenced GeoTIFF output saved straight to your project folder
    • Hooks into the Print Layout window, not the main map toolbar

    This plugin is an early-stage fork of "AI Edit by TerraLab" (GPL-2.0) and is
    being taken in a new direction. It is an independent project, not affiliated
    with TerraLab. See the project README and docs/PLAN.md.
